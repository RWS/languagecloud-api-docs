# AI Agent Development

The Trados Cloud Platform API provides a machine-readable documentation set designed specifically for AI-assisted integrations.This section gives you and your tooling everything needed to understand and call the API correctly.

## What are AI Docs?

AI Docs are a structured documentation set derived from the live OpenAPI specification. They are designed to be consumed by AI agents.

## Starting point for AI agents

If you are wiring up an AI agent or a tool that needs to discover and call Trados Cloud Platform API endpoints, point it at the master index:

**<a href="../aidocs/index.md" target="_blank">AI Docs — Master Index</a>**

The index lists every available operation and links directly to its detail page. From there, your agent can navigate to any endpoint it needs.
